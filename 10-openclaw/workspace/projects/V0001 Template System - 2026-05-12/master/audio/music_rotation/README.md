# Music Rotation

Put the 7 background music files here. The renderer sorts audio files by filename and rotates them like this:

- Video 1 -> music file 1
- Video 2 -> music file 2
- ...
- Video 7 -> music file 7
- Video 8 -> music file 1
- Video 9 -> music file 2

Recommended filenames: `01.mp3`, `02.mp3`, ..., `07.mp3` (or `.wav`/`.m4a`).
