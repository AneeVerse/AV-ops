# AI video automation template-02 — Build Plan

## Decision
Use a 5-section template. This is a good plan because it matches the reference video's real structure and separates the work into reusable modules.

## Section breakdown

### 1) UI scroll section — opening benefit
- Input needed: screenshot 1 and screenshot 2.
- We generate: clean white/gray branded background, headline text, red highlight bar, browser/card frames.
- Motion: screenshot 1 moves right-to-left; screenshot 2 follows behind it like a carousel/continuous horizontal scroll.
- Purpose: show product/platform proof while explaining the main benefit.

### 2) Generated video background — outcome/reach
- Input needed: text/copy direction.
- We generate: industry background video matching the client/business.
- Motion: background video moves naturally; headline/top text animates in; bottom supporting text/logo fades/slides in.
- Purpose: create scale/emotion/outcome scene.

### 3) UI scroll section — problem/solution
- Input needed: screenshot 3.
- We generate: same visual system as section 1.
- Motion: screenshot scroll/pan in lower half; text on top.
- Purpose: show feature proof, metrics, dashboard, or workflow result.

### 4) Generated video background — product/feature intro
- Input needed: text/copy direction.
- We generate: second industry background video.
- Motion: text animates on top; red highlight bar wipes in.
- Purpose: introduce feature/product/offer.

### 5) Outro/logo animation
- Input needed: outro video part or logo asset.
- We use/provide: final logo animation/end card.
- Motion: logo fade/scale/wipe, subtle background pattern.
- Purpose: brand close.

## Inputs Ahmad will provide
- 3 screenshots for sections 1 and 3.
- 1 outro video part for section 5.
- Copy/text for all sections, or brief points so AV_BOT can draft the copy.
- Brand/logo/colors if different from the current reference.

## Outputs to create
- Reusable template structure.
- Generated graphics for sections 1 and 3.
- Generated background videos for sections 2 and 4.
- Rendered final sample video.
- Automation notes for later n8n implementation.

## Recommended duration
- Section 1: 4–5s
- Section 2: 3.5–4s
- Section 3: 3.5–4s
- Section 4: 4–5s
- Section 5: 1–2s
- Total: 18–20s
